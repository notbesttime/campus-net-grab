# 校园网抢抢抢 · 使用说明

高校校园网一键认证工具（Dr.COM / 哆点）：一键完成「检测网络 → 预检占用 → 解绑旧设备 → 门户登录 → 验证联网」，并提供网页控制台管理多账号、查看/解绑绑定设备。

> **使用边界**：本工具仅用于**你自己拥有或已获授权**的校园网账号，并需遵守学校网络管理规定。
> 请勿用于他人账号、规避计费或任何绕过认证的行为。详见文末「免责声明与使用边界」。

## 快速开始

1. 双击 **`启动校园网助手.bat`**
   - 需要电脑装有 [Node.js](https://nodejs.org/zh-cn/download)（一路“下一步”安装即可；未安装时脚本会给出提示）
   - 启动后会**自动打开浏览器**进入控制台（服务只监听本机 `127.0.0.1`，外部访问不到）
2. 在「账号簿」点 **添加账号**：填写账号、服务商后缀（校园用户留空 / 电信 `@dx` / 联通 `@lt`）、备注、密码，勾选“保存到本机”
3. 点 **一键抢网**
   - 若该账号有其他设备在用，会弹窗列出设备，选择 **继续登入** 或 **询问他人**
   - 自助服务登录可能需要**输入一次验证码**（弹窗显示图片）
4. 看到「连接成功」即完成；状态卡会显示在线账号、时长、流量与测试网址结果

> 直接双击 `index.html` 也能打开，但那是**轻量模式**：只能做门户登录/状态检测（解绑、设备管理、密码保存需要本地服务）。
>
> 开发背景与踩坑记录在私有开发仓库中维护，未随本仓库发布。
>
> 在家没有校园网时，本地控制台仍应能打开；只有校园门户、自助后台、绑定设备和 IP 用量需要连接 `HNIST-student`。

## 密码安全

- 密码使用 Windows **DPAPI（当前用户）加密**后保存在本地 `vault.json`，磁盘上**没有明文**
- 密文**绑定这台电脑的 Windows 账户**：把整个文件夹转发给别人，没有你的电脑和账户就是乱码，解不开
- 密码不会写入日志；控制台提供“清除所有保存的密码”
- 忘记密码无法找回（系统不回显），需到校园网渠道重置

## 功能说明

| 位置 | 功能 |
| --- | --- |
| 一键抢网 | 五步流水线实时显示；已在线时只做验证，不会重复登录 |
| 当前状态 | 在线状态 / 认证账号 / IP / 时长 / 流量 / 测试网址（等价于网络列表里的“测试网址”）+ 上次刷新时间；本地服务断开时会明确提示 |
| 各 IP 用量 | 从自助系统的上网记录按 IP 聚合：设备类型（PC/手机）、上次使用时间、上次会话流量、累计流量（统计范围以查询页为准） |
| 账号簿 | 多账号 + 备注 + 服务商后缀，编辑/删除，按账号保存密码；打开表单期间“添加账号”自动置灰防误触 |
| 绑定设备 | 登录自助服务后列出绑定设备（本机高亮），可单个解绑；页面会自动存档到 `diag/` 便于解析问题排查 |
| 设置 | 校园 WiFi 连接（netsh）、抢网成功后自动连 WiFi、诊断模式、清除密码、注销当前会话 |

## 诊断模式（接口有问题时用）

打开「诊断模式」开关后，工具会把自助服务的页面原文保存到 `diag/` 目录（**只存网页响应，密码字段自动打码**）。
绑定设备/用量页面即使不开诊断也会自动存档，方便解析问题排查。
**自动只保留最近 20 个文件**；设置里点「清除诊断信息」可一键全部删除（不影响账号与密码）。
如果“绑定设备/解绑/用量”识别不正确，把 `diag/` 里的文件发给开发者分析即可。

## 目录文件

- `启动校园网助手.bat` — 启动本地服务并打开控制台
- `server.js` — 本地服务（Node.js，零第三方依赖）
- `index.html` / `style.css` / `app.js` — 网页控制台
- `lib/` — 可单测的纯逻辑：解绑目标解析、等待用户输入、文件可靠性、TCP 探测
- `test/` — 单元测试，运行 `npm test`
- `vault.json` — 加密账号保险库（仅密文，自动生成；**已在 `.gitignore` 中排除**）
- `diag/` — 诊断抓取（开启诊断模式后生成；**已在 `.gitignore` 中排除**）
- `LICENSE` — MIT

## 开发

零第三方依赖，需要 Node.js ≥ 18。

```bash
npm start   # 启动本地服务（等价于 node server.js）
npm test    # 运行单元测试（node --test，共 45 个）
```

纯逻辑放在 `lib/` 下，保持无副作用以便单测；改动后请运行 `npm test`。
`.bat` 必须是纯 ASCII 且保持 CRLF。

## 常见问题

- **弹出“访问令牌无效”**：服务重启后旧页面失效，重新双击启动脚本即可
- **自助登录一直要验证码**：该校部署要求验证码，按提示输入即可；成功一次后会话保留，后续抢网一般不用再登
- **提示“未能识别解绑操作”**：开诊断模式抓一次页面交给我，我来补解析
- **换了一台电脑**：密码密文无法解密，重新添加账号输入密码即可
