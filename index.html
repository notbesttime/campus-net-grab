    延迟 一次 TCP 握手要多久。越小越顺：<50 优秀、<100 良好、<200 一般，再慢算较差。
    抖动 多次握手的延迟波动，越小越稳。<10 优秀、<30 良好、<60 一般。忽高忽低比单纯慢更影响体感。
    DNS 把域名解析成 IP 的耗时，越小越快打开网页。<50 优秀、<150 良好、<400 一般。
    首字节 发出请求到收到服务器第一个字节，含服务器自己的处理时间，所以比延迟慢是正常的。<300 优秀、<800 良好、<1500 一般。
    国内/国外 分别测国内站点和境外站点。国外明显偏慢通常是校园出口线路的问题，不是你机器的问题；综合评级取各项里最差的一档。
    检测只做 TCP 握手探延迟，外加向公共测速目标发少量无标识请求（不带 Cookie）；结果只留在页面上，不落盘。默认关闭，在「网络检测」卡片开关处打开。
    1. 点下面的按钮直接跳到 Windows「移动热点」页（也可以自己走：系统设置 → 网络和 Internet → 移动热点）。
    2. 「共享我的 Internet 连接来自」选 WLAN（就是连着 HNIST-student 的这张无线网卡）。
    3. 打开热点开关，记下电脑显示的网络名和密码。
    4. 手机/平板连这个热点就能上网——认证在电脑上，它们不用再登门户，也不用抢网；流量算在电脑这个账号上。
    注意：同一块无线网卡既连网又发热点，速度大约减半；个别老网卡不支持（开关是灰的）。电脑睡眠、合盖或关机后热点会断。别把热点改成开放网络，保持默认的 WPA2+密码。有的学校把「网络共享」视为违规，可能触发风控，请自行确认校园网规定。
    1. 「绑定设备」表里除了 本机，还可能出现 可能本机：这条设备的 MAC 与本机当前网卡不同，但本机以前用过这个 MAC。
    2. 最常见的原因是 Windows 的 Wi-Fi 「随机硬件地址」：同一张无线网卡在不同时间会用不同的 MAC。校园门户因此把同一台笔记本算成两台设备，抢网时还可能提示「账号 PC 名额被占用」——其实那是你自己的旧会话，不是别人。
    3. 怎么关：系统设置 → 网络和 Internet → WLAN → 点你连的那个网络（如 HNIST-student）→ 把「随机硬件地址」设为关闭。关掉后 MAC 稳定，门户只认一台 PC，这类提示自然消失，也不会再出现「解绑了自己又要重登」的来回。
    工具只能根据本机见过的 MAC 历史做推测，所以标「可能」而不是「就是」；它只影响显示与提示文案，不会自动替你解绑。
    维护
    “诊断信息”是 diag 文件夹里的后台页面快照，仅用于解析问题排查；删除不影响账号、密码和任何功能（平时自动只留最近 20 个）。

    关于与使用说明

    校园网抢抢抢 · v1.1.1·更新于 2026-10-15本次有更新
    第一次用，看这里
    1. 把账号加进「账号簿」（学号 + 密码，服务商会自动补 @cmcc）。
    2. 确认「一键抢网时自动连接校园 WiFi」是勾上的，再点一键抢网。
    3. 坐等它自己跑完五步：连 WiFi → 检测在线 → 预检占用 → 门户登录 → 验证放行。
    4. 被名额挡住时它会问你一次，点「解绑并继续」就行——剩下的解绑和重新登录它自己做。
    弹出的上网登录页 / 浏览器窗口被抢走，是正常现象

    抢网时会自动开一个独立的无痕窗口去门户填账号登录，它会短暂抢到前台，也可能让系统弹出一个上网登录页。 不用管它，也不要自己手动登录——脚本会把账号密码中国移动都填好并提交。

    只要界面没有报错，就什么都别点；如果它停在那儿报错了（红色提示），再看提示内容处理。

    这几件事工具会自己做完

    登录成功后它会自动关掉自己开的无痕窗口，并去验证门户、流量和测试网址是否真的放行； 只有「门户在线但数据没通」时才会留一个页面让你自己点一下确认。

    为什么做这个工具

    做一个一键抢网的小工具，初衷很简单：原来借别人校园网的步骤太过麻烦——手动连 WiFi、开浏览器、进门户、填账号密码、点登录，一步都省不掉。现在点一下就好。
